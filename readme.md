# Coffee Shop
## Project Description
A responsive coffee shop site for quick ordering.
## Sprint Goal
I focused on creating the user interface and site links.
## Features Implemented
- As a user I want to add items to my cart to organize my order.
- As a user I want to contact information so I can resolve conflicts.
- As a user I want to order from any device, so I don’t have to order in the shop.
# Technologies Used
- HTML
- CSS
- Java Script
- Responsive Web Design
# Responsive Design
The project was designed to work on multiple devices including portables, dekstops and kiosks.
Flex boxes and clamps were used to achieve this goal.
# How to Run the Project
Load index.html in the project folder into a web browser
